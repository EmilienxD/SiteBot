# @sitebot/cli

`sitebot init` scaffolds configuration and integration. `sitebot validate` validates and prints redacted resolved configuration. `sitebot dev` runs the local server; `sitebot serve` runs a production sidecar. `sitebot doctor` checks provider configuration, storage, security and deployment readiness.

Applications implement all tools and context loading. There is no ingest command or framework knowledge configuration. Scaffolding starts with an empty registry and documents complete explicit application registrations.
